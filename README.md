# Week 2: FinTech Domain & Software

Deliverables for Week 2 of the Bluestock Internship. This week covers stock market fundamentals, financial statement analysis of a listed company, a FinTech industry study, an API-based data task, and a software architecture design.

---

## Deliverables at a Glance

| # | Deliverable | Type | Area |
|---|-------------|------|------|
| 1 | Stock Market Fundamentals Summary | Word | Markets |
| 2 | Financial Statement Analysis (TCS) | Word | Finance |
| 3 | FinTech Research Report (Zerodha) | Word | FinTech |
| 4 | Software Architecture Diagram | PDF | System Design |
| 5 | API Assignment | Python | Development |
| 6 | Users Dataset | CSV | Data |

---

## Contents

### Finance and Markets

| File | Description |
|------|-------------|
| `Stock Market Fundamentals Summary.docx` | Summary of core market concepts: IPO process, book building, how stocks are traded, returns (absolute return and CAGR), and valuation ratios (EPS, PE, PB). |
| `Financial_Statement_Analysis.docx` | Financial statement analysis of TCS, covering performance, profitability and key ratios. |

### FinTech Research

| File | Description |
|------|-------------|
| `FinTech_Research_Report.docx` | Research report on Zerodha: business model, products and position in the FinTech space. |

### Software and Data

| File | Description |
|------|-------------|
| `Software_Architecture_Diagram.pdf` | System design diagram showing the components and data flow. |
| `API_Assignment.py` | Python script for the API assignment. |
| `users.csv` | Dataset used by the API assignment. |

---

## How to Run

Run the script from the folder that contains `users.csv`.

```bash
cd "Week 2"
python API_Assignment.py
```

**Requirements:** Python 3 and the libraries imported at the top of the script.
